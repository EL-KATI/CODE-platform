## القاعدة الذهبية: الشكل + اللون = المعنى

| الشكل واللون | العائلة | المعنى |
|---|---|---|
| مثلث بحاشية حمراء | علامات الخطر | تنبيه بخطر قادم، خفّف السرعة |
| دائرة بحاشية حمراء | علامات المنع | ممنوع ابتداءً من العلامة |
| دائرة زرقاء | علامات الإجبار | يجب اتباع ما تشير إليه |
| دائرة رمادية/بيضاء بخط مائل | نهاية المنع | انتهاء المنع أو التحديد السابق |
| مربع أو مستطيل أزرق | علامات الإرشاد | معلومة (مأوى سيارات P، مستشفى…) |
| مثلث مقلوب | الأسبقية | ليس لكم حق الأسبقية |
| مثمن أحمر STOP | الأسبقية | قف إجبارياً عند الخط |

:::reveal
? فكّر قبل أن تكشف: علامة **دائرية زرقاء** فيها سهم إلى اليمين. ماذا تعني؟
الدائرة الزرقاء = **إجبار**. يجب عليك الاتجاه إلى اليمين.
:::

:::quiz
? دائرة بحاشية حمراء فيها رقم 40. ماذا تعني؟
- [ ] السرعة الدنيا 40 كلم/س
- [x] السرعة القصوى 40 كلم/س ابتداءً من العلامة
- [ ] السرعة المنصوح بها 40 كلم/س
! الدائرة بحاشية حمراء علامة **منع**: يُمنع تجاوز 40 كلم/س ابتداءً من موقع العلامة.
:::

## أين تبدأ علامات الخطر؟

علامات الخطر علامات **متقدمة**، توضع قبل مكان الخطر:

- **150 متراً** خارج التجمعات السكنية.
- **50 متراً** داخل التجمعات السكنية.

:::quiz
? خارج التجمعات السكنية، على أي مسافة تقريباً توضع علامة الخطر قبل مكان الخطر؟
- [ ] 50 متراً
- [x] 150 متراً
- [ ] 500 متر
! خارج التجمعات: حوالي **150 م**، وداخلها حوالي **50 م**.
:::

:::scenario
? تسير خارج المدينة ورأيت مثلثاً بحاشية حمراء يُنبّه إلى منعرج خطير. ماذا تفعل؟
- [ ] أحافظ على سرعتي، فالمنعرج ما زال بعيداً :: خطأ: العلامة وُضعت قبل الخطر بالضبط لتمنحك وقتاً للتخفيف.
- [x] أخفّف السرعة وأستعد للمنعرج :: صحيح: علامات الخطر تطلب الانتباه وتخفيف السرعة.
- [ ] أتوقف فوراً على جانب الطريق :: خطأ: التوقف المفاجئ غير ضروري وقد يكون خطيراً.
:::

## علامات المنع الأكثر طرحاً

- **منع التجاوز**: سيارتان داخل دائرة حمراء.
- **تحديد السرعة**: رقم داخل دائرة حمراء (30، 40، 60، 80…) يبدأ تطبيقه من موقع العلامة.
- **منع المنبه الصوتي**: ليلاً ونهاراً، إلا في حالة خطر داهم.
- **منع الوقوف**: خط مائل واحد — **منع الوقوف والتوقف**: خطان متقاطعان (X).

:::quiz
? علامة دائرية بخطين متقاطعين (X). ماذا تمنع؟
- [ ] الوقوف فقط
- [x] الوقوف والتوقف معاً
- [ ] المرور
! خط مائل واحد = منع **الوقوف**. خطان متقاطعان (X) = منع **الوقوف والتوقف**.
:::

## التشوير الأفقي (الخطوط على الأرض)

- **الخط المتصل**: بمثابة جدار، يُمنع تجاوزه أو المرور فوقه.
- **خط التنبيه المتقارب** والأسهم المائلة: اقتراب خط متصل، ارجع فوراً إلى اليمين.
- **الخط المتقطع العادي**: يسمح بالتجاوز إذا توفرت شروط السلامة.

> 💡 ترتيب الأولوية بين وسائل التنظيم: **شرطي المرور** ← **الأضواء** ← **العلامات** ← **القواعد العامة**.

:::reveal
? شرطي المرور يأمرك بالمرور، لكن الضوء أحمر. لمن تمتثل؟
**لشرطي المرور**. إشاراته أقوى من الأضواء والعلامات والقواعد العامة.
:::

:::summary
- **الشكل + اللون**: مثلث أحمر = خطر، دائرة حمراء = منع، دائرة زرقاء = إجبار، مستطيل أزرق = إرشاد.
- علامة الخطر قبل الخطر بـ **150 م** خارج التجمعات و**50 م** داخلها.
- خط مائل = منع الوقوف، **X** = منع الوقوف والتوقف.
- الخط المتصل جدار لا يُتجاوز.
- الأولوية: الشرطي ← الأضواء ← العلامات ← القواعد.
:::
